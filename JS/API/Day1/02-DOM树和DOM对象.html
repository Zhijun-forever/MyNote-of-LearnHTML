作用和分类： 作用：就是利用js去操作html和浏览器 分类：DOM(文本对象模型) BOM(浏览器对象模型) DOM:Document Object Model 文档对象模型 DOM是浏览器提供的API，js可以通过DOM去操作html页面的内容和结构，DOM是js操作html的桥梁 可以开发常见的网页特效，实现和用户交互 BOM:Browser Object Model 浏览器对象模型 BOM是浏览器提供的API，js可以通过BOM去操作浏览器的相关功能，如窗口、历史记录、导航等 最简单的BOM操作就是alert()，confirm()，prompt()，这些都是浏览器提供的API DOM树： 将html页面的内容和结构抽象成一个树状结构，称为DOM树 DOM树的每一个节点都是一个对象，js可以通过DOM去操作这些对象
