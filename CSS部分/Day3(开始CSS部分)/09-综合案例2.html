CSS(层叠样式表)

CSS（Cascading Style Sheets）是一种用于描述HTML文档外观和格式的样式表语言。它允许开发者控制网页的布局、颜色、字体等视觉元素，使得网页更加美观和易于阅读。

CSS的基本语法由选择器和声明块组成。选择器用于指定要应用样式的HTML元素，而声明块包含一个或多个声明，每个声明由属性和对应的值组成。例如：

        h1 {
            color: blue;
            font-size: 24px;
        }
  • 选择器：用于指定要应用样式的HTML元素。
  • 声明块：包含一个或多个声明，每个声明由属性和对应的值组成。
  • 属性：用于指定要设置的样式特性，例如颜色、字体大小等。
  • 值：用于为属性指定具体的样式，例如红色、16px等。
